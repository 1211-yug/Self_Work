
# 💳 Awesome Flip Card

An interactive 3D flip card built using HTML, CSS, and JavaScript. Click the card to see a smooth flipping animation that reveals the front and back sides.

## Live Demo :- https://flip-card-1.netlify.app/

## ✨ Features

- Interactive click-to-flip functionality
- Smooth 3D flip animation
- Attractive gradient backgrounds
- Front and back card designs
- CSS transitions and 3D transforms
- Simple and beginner-friendly code

## 🛠️ Technologies Used

- **HTML5** 
- **CSS3** 
- **JavaScript**
