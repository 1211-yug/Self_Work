# 🛍️ TRENDORA – Fashion E-commerce Website

TRENDORA is a modern, responsive fashion e-commerce landing page built with HTML and CSS. It has a bold red and black design and a clean layout.

## 🔗 Live Demo

👉 [View Live Demo](https://tren-dora.netlify.app/)

## ✨ Features

- Responsive design for mobile, tablet and desktop
- Hero section with fashion images
- Product showcase sections with name and price
- "What Everyone's Wearing" collection section
- Newsletter signup with a 15% first-order offer
- Footer with contact details and social media links

## 🛠️ Built With

- HTML5
- CSS3
- Font Awesome (icons)
