# 🔢 Counter Application

A simple, modern, and interactive Counter Application built using **HTML, CSS, and JavaScript**. This project allows users to increase, decrease, and reset the counter value with dynamic text color changes.

## 🚀 Live Demo

counter-numb.netlify.app

## 📸 Features

- ➕ **Increase:** Increment the counter value by 1.
- ➖ **Decrease:** Decrement the counter value by 1.
- 🔄 **Reset:** Reset the counter value to 0.
- 🎨 **Dynamic Colors:** The counter text changes color based on its value.
  - Green when the value is positive.
  - Red when the value is negative.
  - White when the counter is reset.
- ✨ **Modern UI:** Gradient background, glass-style card, shadows, and hover effects.
- 📱 **Responsive Design:** Flexible layout for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling, gradient background, transitions, and hover effects.
- **JavaScript** – Counter logic, DOM manipulation, and event listeners.
